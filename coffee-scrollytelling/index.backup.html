PHASE 01 // 00:00 - 04:30

入豆吸熱與含水率均勻化

生豆入鍋後吸收滾筒儲備熱能，達到回溫點（Turning Point）。此階段首重透過穩定風門帶走生豆蒸散的游離水氣，確保豆芯受熱均勻。

PHASE 02 // 04:30 - 08:00

梅納反應與芳香物質前驅物生成

豆色轉為金黃並伴隨烤麵包香氣。胺基酸與還原糖在熱力驅動下快速縮合，生成複雜的類黑素，奠定咖啡厚實醇厚度與基礎風味基調。

PHASE 03 // 08:00 - 09:40

一爆劇烈裂解與發展時間控制

內部蒸氣壓力撐破細胞壁釋放密集爆裂聲，烘焙進入放熱反應。嚴格控管 RoR 衰退斜率（DTR 控制於 13-16%），保留細緻的花果酸質調性。

PHASE 04 // 09:40 - 10:30

精準出鍋排氣與急速風冷

達到預定烘焙度（Agtron 數值）後果斷開閘出鍋。藉由強力抽風在 2.5 分鐘內將豆溫驟降至室溫，精準鎖定焦糖化終點，避免餘熱自焙。
